## 1. 统一风格提示词

所有资源必须保持统一的视觉风格：

```
中国悬疑推理视觉小说，海上孤岛古堡，暴风雨夜，低饱和电影感，
暗金与深蓝色调，写实插画风，细腻光影，严肃氛围，无文字，无水印
```

**扩展说明**：
- **色调**：暗金（#c9a227）、深蓝（#0f1520）、深红（#8b3a3a）作为主辅色
- **氛围**：暴风雨夜的孤岛古堡，昏暗、紧张、悬疑感
- **风格**：写实插画风，非卡通、非二次元
- **光影**：戏剧性光影（蜡烛、台灯、月光），对比度偏高
- **构图**：视觉小说常用 16:9（场景）和 2:3（人物立绘）
